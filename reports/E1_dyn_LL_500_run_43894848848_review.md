## Edge-ranking diagnostics

- Greedy versus Pearson top-20 overlap: **18/20 edges**. Both have TP@20 = 10. Improvement in AP therefore does not imply improved top-20 recovery.
- Greedy versus Spearman top-20 overlap: **12/20**.
- Greedy top-20 contains **eight reciprocal pairs (16/20 predictions)**: g10/g11, g9/g10, g11/g12, g4/g5, g5/g6, g6/g7, g7/g8, g8/g9.
- Raw Pearson absolute correlation is symmetric in edge direction. Greedy conditioning allows graph-level interactions but still readily selects both directions.
- The current output does not contain per-edge gold labels, so this artifact alone cannot identify exactly which named predictions are true or false. Generate annotated rankings **only at evaluation time** in the next workflow.

**Scientific implication:** promising nonrandom prediction and conditional graph search, but **directed regulatory inference remains insufficiently resolved**. Reciprocal edges are not universally biologically invalid, but widespread reciprocal pairs require attention in this synthetic linear network. Use pseudotime/temporal/perturbational direction evidence and clearly stated structural alternatives, with fair ablations.

## Decision and next experiments

**Conditional M1 acceptance:** proceed with software development, but do not claim any RL or adaptive prior improvement. Before M2/M3:

1. **Reference provenance:** reconcile 19 versus 18 gold edges and preserve original, filtered and excluded counts/reasons.
2. **Metric comparability:** report `average_precision` explicitly, compare BEELINE's AUPRC implementation, and retain both if they differ.
3. **Directionality audit:** count reciprocity/2-cycles and assess orientation separately; evaluate pseudotime-informed candidate features/temporal models without using reference labels as model inputs.
4. **Independent expression holdout:** fit train / score graph edits on development / evaluate expression fit on never-queried test cells; no re-tuning after examining results.
5. **Stability and budgets:** repeat on 10 BEELINE dyn-LL replicates and at least one different network topology, seeds, 5/10/20/30-edge budgets, and sparse penalties. Report CI at independent replicate level.
6. **Mechanism control:** compute conditional gain versus the same edge in an empty graph and graph with pre-existing target parents; check whether sequential interactions actually affect selections.
7. **Only then:** implement fixed biological priors and the cross-fitted reliability learner. RL must be compared with the same utility against fully matched greedy/beam/local-search controls.
