## Scanning and uncertainty rules
1. With canonical alphabet A/C/G/T and global, precommitted uniform background `b=[0.25]*4`, compute per-position `PWM=log2(max(p,1e−6)/0.25)` and the motif minimum/maximum possible log-odds scores. The normalized match is `r=(raw_log_odds−min_possible)/(max_possible−min_possible)`, clipped to [0,1]. Unrecognized bases make that window unscorable, not negative evidence. Scan all positions in both strands of the **gene-oriented** promoter; record TF, target, source motif ID, maximal relative score, genomic position and strand relative to transcription, top matched DNA sequence. If TF=target, exclude self-edge *before* scoring.
2. **Dinucleotide-preserving null:** for each target-gene promoter, generate exactly **128** deterministic shuffled sequences using randomized Euler trails, same starting and ending nucleotide, exact original dinucleotide multiset and length; random seed from SHA256(protocol ID + target gene ID) and RNG `np.random.default_rng`. Reuse the identical 128 null promoters across every TF/motif. Verify dinucleotide counts for every shuffled sequence. Do not shuffle K562 expression or use any observed TF–target truth.
3. For each TF/promoter, compute the maximum relative motif score over its registered motifs and **both strands**, for the genuine sequence and each dinucleotide-null sequence. Empirical one-sided p `(1+Σ null_max≥observed_max)/(129)`, null median and 95th percentile (linear interpolation). Define continuous **sequence-based prior strength** `clip((observed_max − null_median)/(1−null_median),0,1)`; if null median≈1 fail safely; raw negative contrasts become 0. This is **not** a posterior probability of regulatory binding. To avoid overclaiming, report p separately and BH-adjust across **all 1,008** tested edges; no hard biological label from p/q.
4. Also report `observed_minus_null95` and whether observed max exceeds null 95th percentile as **descriptive** enrichment diagnostics. The null preserves dinucleotide counts but not chromatin context, sequence accessibility, nucleosomes or TF abundance. No motif evidence establishes K562 TF occupancy.
5. Each of the **16×64−16=1,008** ordered TF→target edges must have exactly one fully observed score record: includes `prior_score`, `observed_best_pwm_relative`, `null_median_pwm_relative`, `null_95th_pwm_relative`, `empirical_p`, `bh_q`, `best_motif_id`, `best_position_0based`, `best_strand_gene_orientation`. Never recode zero prior scores as missing; distinguish missing source data from computed zero.
6. Fit/score/test cell partitions and 64-gene list remain **immutable**; promoter source is an orthogonal, publicly available sequence/motif *potential-binding prior*, not a confirmed TF→target regulatory reference. The prior may not be independent of future experimental biological priors and must be audited separately against any held-out assay.
