# BIO-V2 — ENCODE K562 CRISPRi experimental quality and count-based response qualification

**Frozen input panel**: `configs/encode_crispri_k562_panel_2026_11_25.json`, six TF perturbations (TFDP1, KLF2, NR2F2, RELA, SP1, NR2C2) versus non-targeting ENCSR095PIC. Input experimental design source qualification and 17 per-biosample GRCh38/V29 gene TSVs passed in GitHub [run 45797283352](https://github.com/TshepoGobonamang/bio-rl-grn/actions/runs/45797283352). That earlier run calculated descriptive TPM ratios, **not DE significance**.

## Locked stage requirements and scopes

1. Download original GENCODE v29 GRCh38 gene annotation from `https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_29/gencode.v29.annotation.gtf.gz`; retain source SHA256 and parse only authentic `gene` rows (`gene_id`, `gene_name`). Match versioned Ensembl IDs exactly, preserve spike-ins separately; reject ambiguous TF gene-symbol mapping. Source: https://www.gencodegenes.org/human/release_29.html.
2. Reread original ENCODE experiment JSON and resolve biological samples from `replicate -> library -> biosample` with explicit unique biosample accession and original hashes. Choose only pre-frozen GRCh38 GENCODE V29 released *per-biological-replicate* gene quantifications. Download each original TSV with verified ENCODE-provided MD5 and content length. Never count different libraries, annotations or files as biological replication.
3. **Sample QC:** per-sample RSEM expected-count library totals, expressed ENSG count, nonzero TPM count, log2(TPM+1) pairwise sample Spearman correlation, sample PCA from the 2,000 most variable common genes. There are six treatment arms sharing the same two controls; treatment replicate count 2 or 3. Flags should trigger manual investigation, **not automatic outlier deletion**.
4. **TF-knockdown mRNA diagnostic:** map six TF symbols via original GENCODE V29, report exact versioned gene IDs, each individual treated/control TPM and source files, mean abundance ratio with +1 pseudocount, and whether treated replicates fall below the control mean. A negative mRNA ratio does **not** prove protein-level knockdown or rule out cell-composition artifacts; no unverified TF→target edges.
5. **Count-based expression response:** use RSEM `expected_count`, `TPM`, `effective_length` from the *same original gene-quantification TSVs*. Feed matched matrices to DESeq2 via the tximport gene-level structure with original estimated counts and effective-length offsets. **Do not treat TPM as DESeq2 count input.** Exclude zero-length genes; prefilter `rowSums(expected_count)>=10`; then DESeq2 Wald test, unshrunk log2FC, BH-FDR 0.05, treatment vs control with `~condition`, no technical replicate pooling; all retained gene rows exported with p and padj. Report exact number of passing gene filters, FDR calls, R/DESeq2 versions and file/checksum provenance. The small isogenic replicate count limits power. The fixed gene-level tximport structure and versioned gene IDs require review against RSEM upstream transcript-specific effective-length assumptions before confirmatory publication.
6. **Scientific gate:** No GCEV ranking files, no source-disjoint prior reference, no direct TF-binding truth, and no independent uninspected ENCODE outcome panel are available in BIO-V2. Thus BIO-V2 only qualifies real K562 perturbation response measurements. Shared controls create dependence across TF contrasts. FDR-significant response genes may be direct OR indirect, while non-significant genes are **unknown**, not verified negative edges.

### Outputs

- `gcev-encode-biov2-original-source-qc`: ENCODE and GENCODE source hashes, 17-sample QC, PCA, replicate correlations, TF mRNA diagnostics, and per-TF matched RSEM `expected_count`, TPM, effective-length matrices and sample provenance.
- `gcev-encode-biov2-deseq2-statistical-results`: count-based DESeq2 per-gene results and six-TF summary if and only if the DESeq2 job completes.

**Acceptance**: Both artifacts must execute against original files, every source hash verified, per-replicate experiment identity maintained, TF knockdown reported without assuming efficacy, all DE results supported by explicitly labelled count-based method and multiple testing correction. No biological GCEV superiority claim at this stage.
