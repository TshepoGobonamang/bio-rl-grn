# Data provenance

Do not commit downloaded raw BEELINE archives or normalized expression matrices.

data/raw/beeline/ stores source files. data/processed/ stores standardized
samples-by-genes matrices and manifest with original SHA256 hashes.

BEELINE v4 https://zenodo.org/records/19009603
BEELINE documentation https://murali-group.github.io/Beeline/reproducing-results.html
Paper: Pratapa et al. (2020), Nature Methods, DOI 10.1038/s41592-019-0690-6.

BEELINE reference data have separate distribution terms; inspect source licenses.
